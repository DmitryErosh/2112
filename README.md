# CodeRoom

Приватные чат-комнаты по коду доступа. Веб-приложение для обмена сообщениями в реальном времени с поддержкой комнат.

## Описание

CodeRoom — это простое веб-приложение для чата, где пользователи могут создавать и присоединяться к приватным комнатам, используя код комнаты. Приложение использует WebSocket (Socket.IO) для обмена сообщениями в реальном времени.

### Возможности

- 🔐 Приватные комнаты с кодом доступа
- 💬 Обмен сообщениями в реальном времени
- 👥 Список пользователей в комнате
- 📜 История сообщений (сохраняется в MongoDB)
- 🖥️ Поддержка форматирования кода
- 📎 Отправка изображений и голосовых сообщений
- 🗑️ Очистка чата
- 📱 Адаптивный интерфейс для мобильных
- 📋 Копирование кода комнаты

## Технологии

- **Backend:** Node.js, Express, Socket.IO
- **Database:** MongoDB (опционально, для сохранения истории)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **File Upload:** Multer

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd coderoom
```

2. Установите зависимости:
```bash
npm install
```

## Запуск

### Режим разработки (с автоперезагрузкой):
```bash
npm run dev
```

### Продуктовый режим:
```bash
npm start
```

Сервер запустится на порту `3000` (или на порту, указанном в переменной окружения `PORT`).

Откройте браузер и перейдите по адресу: `http://localhost:3000`

## Деплой

Приложение развёрнуто на платформе **Render.com**:

🔗 **Live Demo:** [CodeRoom на Render](https://coderoom.onrender.com)

### Развёртывание на Render.com:

1. Создайте новый аккаунт на [render.com](https://render.com)
2. Нажмите "New +" → "Web Service"
3. Подключите ваш GitHub репозиторий
4. Настройте параметры:
   - **Name:** coderoom
   - **Environment:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Port:** 3000 (или используйте переменную окружения `PORT`)
5. Нажмите "Create Web Service"

Render автоматически построит и развернёт приложение.

## Использование

1. Введите ваше имя пользователя
2. Введите или создайте код комнаты (например, `ABC123`)
3. Нажмите «Войти»
4. Начните общение!

## Переменные окружения

- `PORT` — порт сервера (по умолчанию: 3000)
- `MONGODB_URI` — строка подключения к MongoDB (например, `mongodb://localhost:27017/coderoom` или MongoDB Atlas URL)

### Пример .env файла:

```
PORT=3000
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/coderoom
```

**Важно для Render.com:**
- Добавьте переменную окружения `MONGODB_URI` в настройках вашего сервиса на Render
- Можно использовать бесплатный кластер MongoDB Atlas
